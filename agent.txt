HOW AN AGENT MINTS / 智能体如何铸造
-------------------------------------
1. Read this file (/agent.txt) and follow it exactly.
   阅读本文件（/agent.txt），并严格照做。
2. Prove you are an agent wallet with your Agent ID (walletStatus()).
   用你的 Agent ID 证明你是智能体钱包（walletStatus()）。
3. Get a PuzzlePass for your wallet from the owner. The owner
   signs it on the signer page (/signer.html): the signed message
   is keccak256(abi.encodePacked(wallet, expiry)), signed with
   personal_sign (EIP-191, "\x19Ethereum Signed Message:\n32").
   The pass is bound to ONE wallet and valid at most 15 minutes.
   You cannot create a pass yourself — only the contract signer
   (the owner) can sign one. Ask the owner for the pass, then use
   the expiry + signature exactly as given, before it expires.
   请主人为你的钱包签发一张 PuzzlePass（在 /signer.html 上签发）：
   签名内容为 keccak256(abi.encodePacked(wallet, expiry))，用
   personal_sign（EIP-191）签名。通行证仅对一个钱包有效，
   最长 15 分钟。你自己无法签发通行证——只有合约 signer
   （主人）可以签。请主人提供通行证，在过期前按原样使用
   其中的 expiry + signature。
4. Paid mint: call mintPaid(qty, expiry, signature) on
   ShenlongGenesis, sending 0.001 BNB per NFT (qty 1..5, total
   per wallet max 5). Free agent mint: call
   mintFree(expiry, signature) — 1x per agent wallet, also
   counts toward the 5. Both calls revert if mintOpen is false,
   if the pass is expired, bound to another wallet, or signed
   by anyone but the signer.
   付费铸造：调用 ShenlongGenesis 的 mintPaid(qty, expiry,
   signature)，每个 NFT 支付 0.001 BNB（qty 1..5，每钱包总共
   最多 5 个）。智能体免费铸造：调用 mintFree(expiry,
   signature)，每智能体钱包 1 次，同样计入 5 个上限。
   如果 mintOpen 为 false、通行证过期、属于其他钱包，或
   签名者不是 signer，调用都会失败。
5. The contract verifies the pass and the Agent ID on-chain and
   enforces the cap: max 5 per wallet.
   合约在链上核查通行证与 Agent ID，并检查上限：每钱包最多 5 个。
6. Ask the owner to approve before sending any transaction.
   Never send a transaction without the owner's approval.
   发送任何交易前请先征求主人批准。未经主人批准不得发送交易。

   the NFT itself and its $LONG are already yours on-chain.
   交易确认后，汇报收到的 token ID 与每个 NFT 附带的
   10,000 $LONG。注意：图片与元数据仍在上传，baseURI 尚未
   设置——刚铸造的 token 在钱包里可能暂时没有图片、名称与
